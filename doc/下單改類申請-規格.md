# 下單改類申請 — 規格卡片

> 來源：`index.html`。模組與機制合併呈現；判讀不確定處標 `⚠ 待確認`。

## 一、模組規格（模組／內容／觸發·機制）

1. `<新增>` **頁首品牌列**
   - 內容：口袋證券 logo＋品牌文字；右側「登出」
   - 觸發／機制：
     1. 點品牌 → 導向官網 `https://www.pocket.tw/`（`target="_blank"`）
     2. 點「登出」→ ⚠ 待確認：正式系統登出行為（Demo 無綁定）

2. `<新增>` **頁面標題與 Tab**
   - 內容：標題「下單改類申請」；Tab「改類申請」「申請紀錄」
   - 觸發／機制：
     1. 點「改類申請」→ 顯示申請視圖（`#apply`）
     2. 點「申請紀錄」→ 顯示紀錄視圖（`#records`）
     3. 空狀態視圖（`#empty` 或 `?view=empty`）→ 隱藏 Tab

3. `<新增>` **改類申請／查詢列**
   - 內容：證券帳號唯讀（顯示「姓名＋帳號」，例：陳小傑 6620-0385361）；股票代號搜尋框；「搜尋」
   - 觸發／機制：
     1. 輸入關鍵字後點搜尋／送出表單 → 依代號或名稱篩選申請列表
     2. 頁面鎖定時（信用戶／融資餘額進場攔截後）→ 搜尋框與按鈕 disabled

4. `<新增>` **改類申請名單表**
   - 內容：欄位＝股票名稱（代號＋名稱）、單價、可改類張數、改資買張數（stepper）、預估融資金額；表尾「本次預估融資 ○○ 元，申請後剩餘額度 ○○ 元」；無資料時「查無符合的資料」
   - 觸發／機制：
     1. 點表頭「股票名稱／單價／可改類張數」→ 升／降冪排序切換
     2. 點 stepper「−／＋」或直接輸入 → 改資買張數限制在 `0～可改類張數`；同步該列預估融資與表尾合計
     3. 預估融資＝單價 × 改資買張數 × 1000（股／張）
     4. 申請後剩餘額度＝客戶融資額度上限 − 本次預估融資合計；餘額＜0 時表尾行警示樣式
     5. 改資買張數＞0 的列 → 列高亮；「下一步：送出」才可點
     6. 頁面鎖定時 → stepper 不可操作

5. `<新增>` **下一步：送出**
   - 內容：頁底主 CTA「下一步：送出」（預設 disabled）
   - 觸發／機制：
     1. 至少一筆改資買張數＞0 且未鎖定／未送出中 → 可點
     2. 點擊且申請後剩餘額度＜0 → 不開確認窗，改開「融資餘額不足」視窗（`quota-next`）
     3. 點擊且額度足夠 → 開「確認改類」視窗

6. `<新增>` **確認改類視窗**
   - 內容：警示「送出後不可更改…」；摘要表（股票名稱、可改類張數、改資買張數、預估融資金額）；表尾同申請表的預估融資／剩餘額度；「取消」「送出申請」
   - 觸發／機制：
     1. 點「取消」或 Esc → 關閉視窗，回到申請頁
     2. 點 backdrop → 不關閉
     3. 點「送出申請」→ 關閉確認窗，依結果開提示視窗（見模組 8）；成功時清空張數並寫入申請紀錄；配額不足亦寫入紀錄；連線異常不寫入
     4. ⚠ 待確認：正式送出 API 成功／配額不足／連線異常判定規則（Demo 可用 `?submit=success|source|network` 或隨機）

7. `<新增>` **進場／攔截提示視窗（共用 notice）**
   - 內容：依情境切換標題、文案、按鈕
   - 觸發／機制：
     1. **現股改融資說明（convert）**：僅「確認」；關閉後可操作申請頁
        - 紅字：目前僅支援將「現股買進」變更為「融資買進」。
        - 文案：變更前請確認您已開通信用交易資格，且融資額度足夠。變更後系統將檢核該檔股票的融資配額，若配額不足，請洽客服中心 0809-089-001 詢問。是否確認辦理交易類別變更？
     2. **未開信用戶（credit）**：「取消」「前往信用戶開戶」
        - 黑字：您尚未開立信用戶，請您前往開立信用戶
        - 紅字：信用戶開戶需經審核，預計審核日為兩個工作天
        - 點「前往信用戶開戶」→ 導向開戶 URL（Demo 為 `#`，關閉後鎖定申請頁）
        - 點「取消」／Esc（攔截情境）→ 導向官網 `https://www.pocket.tw/`
     3. **融資餘額不足（quota／quota-next）**：標題「融資餘額不足」；「取消」「前往額度申請」
        - 黑字：您現在融資餘額為 {金額} 元，請調整改資買張數，或前往額度申請提高融資額度
        - 紅字：線上額度申請僅限第一類帳戶及第二類帳戶，調整額度需經過元大證金審核，預計審核日為兩個工作天
        - 進場 `quota`：取消 → 回官網；確定後鎖定申請頁（Demo URL `#`）
        - 送出前攔截 `quota-next`：取消／Esc → 僅關窗，不鎖定、不回官網；可回表調整張數
     4. backdrop 不可關窗
     5. ⚠ 待確認：進場三種提示在正式系統的觸發條件（Demo：`?notice=credit|quota|convert`，未指定則隨機）

8. `<新增>` **送出結果提示視窗**
   - 內容：僅「我知道了」；標題「提示」
   - 觸發／機制：
     1. 成功 → 「已成功送出申請，請稍等5分鐘後至申請紀錄及口袋台股確認」
     2. 配額不足 → 「配額不足，請於T+2日確認交割帳戶有足額交割款」＋客服電話 `0809-089-001`
     3. 連線異常 → 「連線異常，請稍後5分鐘再次申請」＋客服電話
     4. 點「我知道了」／Esc → 關窗

9. `<新增>` **申請紀錄／查詢條件**
   - 內容：證券帳號唯讀；申請日期起／迄、股票名稱、狀態（全部／已通過／配額不足）；「清除」「查詢」
   - 觸發／機制：
     1. 點查詢 → 依條件篩選紀錄表
     2. 點清除 → 清空條件並重繪完整列表

10. `<新增>` **申請紀錄表**
    - 內容：欄位＝申請日期、股票名稱、單價、可改類張數、改資買張數、狀態（已通過／配額不足）；空狀態「尚無申請紀錄」或「查無符合條件的申請紀錄」
    - 觸發／機制：
      1. 點可排序表頭（申請日期／股票名稱／單價／可改類張數／狀態）→ 升／降冪切換
      2. 送出成功或配額不足後 → 寫入本機紀錄並可在此查看（Demo：`localStorage`）
      3. ⚠ 待確認：正式系統狀態是否僅此兩種、是否另有「其他」等後備狀態

11. `<新增>` **空狀態頁（無單／逾時）**
    - 內容：「您今日無下單紀錄或超過可改類時間，若有需求，請於服務時間聯絡客服：0809-089-001」（電話可點撥）
    - 觸發／機制：
      1. 進入 `#empty` 或 `?view=empty` → 顯示此頁並隱藏 Tab
      2. ⚠ 待確認：正式系統進入條件（無當日可改類單／超過可改類時間，約 15:00）與是否仍可切申請紀錄

## 二、規格說明（全域／純視覺／約束）

- **全域 — 路由／視圖**：`#apply`／`#records`／`#empty`（或 `?view=` 同值）切換視圖；離開申請頁時關閉確認窗；非攔截型提示可隨之關閉
- **全域 — 頁面鎖定**：信用戶／進場額度不足確定後，申請面板鎖定（搜尋、排序、stepper、下一步皆不可用）
- **全域 — 取消回官網**：僅進場攔截（credit／quota）的「取消」與對應 Esc → `https://www.pocket.tw/`；確認改類「取消」、送出前額度不足「取消」、送出結果「我知道了」皆只關窗
- **全域 — 融資試算**：預估融資＝單價 × 改資買張數 × 1000；剩餘額度＝客戶融資額度上限 − 合計（Demo 上限固定 2,000,000）
- **全域 — 狀態用語**：申請紀錄與送出結果對外顯示「配額不足」（勿用「券源不足」）
- **設計提醒**：對齊口袋證券品牌色（紅主色／粉紅底／灰階）；數字用 Inter；中文用 PingFang TC／Noto Sans TC；modal 警示紅字用 `pkt-modal__notice--alert`
- **Demo 參數（非正式規格）**：`?notice=`、`?balance=`、`?submit=`、`?view=` 僅原型模擬用

### ⚠ 待確認清單
1. 「登出」正式行為與是否本頁提供
2. 信用戶開戶、額度申請的正式 URL
3. 進場提示（信用／額度／改類說明）正式觸發條件，是否互斥、是否可關閉後重開
4. 融資額度上限、融資餘額數值來源（客戶端即時查詢 vs 後端）
5. 送出 API 回應對應成功／配額不足／連線異常的正式規則
6. 可改類時間截止（約 15:00）與空狀態進場條件
7. 申請紀錄正式狀態集合是否僅「已通過」「配額不足」
8. 成功後「5 分鐘後至申請紀錄及口袋台股確認」是否為固定文案／SLA
9. 同一股票多筆成交列（Demo 有多列同代號）正式是否分列顯示、是否可合併改類
